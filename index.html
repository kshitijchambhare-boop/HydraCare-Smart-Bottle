            Future Hardware Integration

            The simulation talks to one adapter, HydrationAPI.ingest(). A real ESP32 replaces the buttons by sending the same JSON:

            {"event":"drink","ml":250,"weight":610,"temp":22.4}

            Load cell → weight → level (weight − bottle tare). A weight drop = drink; a jump up = refill. The ESP32 buzzer/LED replaces the sound alert. Send data over Wi-Fi (HTTP/MQTT) to a small Node.js/Express bridge (server.js), which the dashboard can read.
